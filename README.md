# 🌌 NASA Space Invaders: Nebula Command Deck

A classic 2D retro arcade Space Invaders shooter built entirely with **Vanilla JavaScript** and **HTML5 Canvas**. The game is wrapped in an immersive, sci-fi bento-grid telemetry dashboard that updates dynamically using real cosmic data pulled from the **NASA APOD (Astronomy Picture of the Day) API**.

---

## 🚀 Key Features

- **Dynamic Cosmic Levels:** Every time you clear an alien fleet and advance a level, the game queries the NASA API to fetch a random cosmic photograph from the past 2 years to serve as your new scrolling combat backdrop.
- **Nebula Command Deck UI:** A responsive Bento Grid layout displaying live telescope telemetry metadata (object title, description, and capture dates), active score tickers, level progression rings, and terminal diagnostic interfaces.
- **Boss Fights:** Survive standard fleet waves to trigger massive, high-health alien capital ship boss encounters on every 3rd level.
- **Native Audio Synthesizer:** Built entirely on the browser's native Web Audio API to generate procedural 8-bit laser fires, rhythmic march tempos, and crunching explosions without loading a single heavy sound file.
- **Pure Vanilla Architecture:** Zero external libraries, dependencies, or heavy runtime frameworks (No React, No Phaser, No jQuery).

---

## 🛠️ Design System & Aesthetic

Inspired by futuristic aerospace HUD telemetry panels:
- **Typography:** `Orbitron` for arcade cabinet display headings, `Rajdhani` for core interface layouts, and `Share Tech Mono` for continuous data reads.
- **Color Identity:** Dark spaceship cockpit depth profiles (`#0B0F19`) accented by striking holographic neon cyan highlights (`#00F0FF`) and critical system amber alerts (`#FF9500`).

---

## 🎮 Controls

- **Spacebar:** Launch Mission / Fire Lasers
- **Left Arrow / A Key:** Move Starship Left
- **Right Arrow / D Key:** Move Starship Right
